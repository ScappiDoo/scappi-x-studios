scappi-x-studios

What this folder does

A one-page GitHub Pages site for the studio, served at https://scappidoo.github.io/scappi-x-studios/. It says who Scappi X Studios is and sends readers to the real site at https://vanillax.pages.dev. Its job is discoverability: a second, fast-to-index address that repeats the canonical VanillaX sentence and links both ways with the main site. It uses the same design as the main site.

Non-obvious logic

Organization uses the main site's id
The JSON-LD Organization has @id https://vanillax.pages.dev/#org, the same id as on the main site, so search engines treat both pages as describing one company. This page's URL is listed in its sameAs, and the main site lists it back.
No JavaScript
The main site's nav script needs the account API, so it is left out. All links to the main site are absolute.
Own canonical
The page is a studio page with its own text, not a copy of a main-site page, so it is canonical to itself.

Gotchas and invariants

  • The first sentence about VanillaX must be the canonical sentence from the brand repo (ScappiDoo/scappitrade-plg, brand/VANILLAX_ENTITY.md). Never paraphrase it.
  • Write the names exactly: VanillaX, Scappi X Studios (three words), X Geopol (a server, not a plugin).
  • The address must keep the trailing slash in every link, because GitHub Pages serves the folder.
